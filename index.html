neosloc

sloccount counted lines and priced them with COCOMO. With LLMs writing code, lines are cheap. neosloc measures what still costs something: how easily other systems and agents can use a project, what it is worth, and whether to adopt it or rebuild it.

pip install neosloc        # or: pipx install neosloc / uv tool install neosloc
neosloc path/to/repo

What it reports

Ten dimensions

Interface, stability, events, identity, portability, agent ergonomics, embeddability, extensibility, observability and change legibility, each a ladder of checkable requirements.

Per surface

Services, CLIs, libraries, desktop apps and frontends are judged on their own terms; dimensions that can't apply are n/a, not zero.

Make or buy

Tokens, agent hours and human days to rebuild it with agents, against minutes to adopt it as it is.

neoCOCOMO

What a codebase is worth when agents can re-type it, and how much of it lives only in its history.

LLM evaluators

A probe tries real integration tasks from the docs; a judge and a review panel check the results. Anthropic or OpenRouter.

Built for scripts

JSON output and errors that follow a published schema, typed exit statuses, structured logs. No dependencies, Python 3.8+.
